# Kiva Software

**Status: exited — acquired by Netscape Communications, December 1997. No active developer surface.**

Kiva Software Corporation pioneered the internet application server. Founded in May 1994 by chairman and CEO Keng Lim in Mountain View, California, Kiva shipped in January 1996 what is widely credited as the industry's first web application server — and the first Java application server to market, with C++ application development supported alongside it.

The product line was the **Kiva Enterprise Server** (deployment and management runtime), the **Kiva Application Builder** (graphical development tool), and the **Kiva SDK** (Java and C++ foundation classes), supported by the Kiva Enterprise Alliance Program (KEAP). Customers included Bank of America, E-Trade, Travelocity, Internet Shopping Network, Hong Kong Telecom, and Pacific Bell Internet.

Kiva raised roughly $13.9M across two rounds from Weiss Peck & Greer, Greylock, Discovery Ventures, Sippl MacDonald Ventures, Norwest Venture Capital, and Trinity Ventures, and appears in the Lightspeed Venture Partners portfolio as a 1996 early-stage investment.

In December 1997 Netscape Communications acquired Kiva for approximately $180 million in stock (6.3 million Netscape shares). The Kiva Enterprise Server became the **Netscape Application Server**, then the **iPlanet Application Server** under the AOL/Netscape–Sun Microsystems alliance, and later Sun ONE / Sun Java System Application Server.
